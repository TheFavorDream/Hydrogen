# Hydrogen, A Simulation/Rendering Engine

Hydrogen is suppose to a Simulation & Rendering Engine, Designed to aim at performance.

This project is still under development and misses a lot of things, but I'am very optimistic about the results

---

## Goals

The Goals of Hydrogen are:

- An efficient Hybrid Renderer
- A Custom & Optimized Memory Managment Model
- A Rich scripting Language (Lua for now)
- High Accuracy in computing
